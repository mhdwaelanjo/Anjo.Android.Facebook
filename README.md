# Anjo.Android.Facebook

---------------------------------
Facebook SDK for .NET for Android (formerly Xamarin.Android) Binding Library - Wael Anjo
---------------------------------

This library allows you to integrate Facebook into your Android app.
Learn more about the provided samples, documentation, integrating the SDK into your app, accessing source code, and more at
https://developers.facebook.com/docs/android

Quickstart for Android : https://github.com/facebook/facebook-android-sdk
