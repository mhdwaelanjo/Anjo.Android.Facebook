# Anjo.Android.Facebook.Messenger

---------------------------------
Facebook.Messenger SDK for .NET for Android (formerly Xamarin.Android) Binding Library - Wael Anjo
---------------------------------

[![NuGet Version](https://img.shields.io/nuget/v/Anjo.Android.Facebook.Messenger)](https://www.nuget.org/packages/Anjo.Android.Facebook.Messenger) [![GitHub License](https://img.shields.io/github/license/mhdwaelanjo/Anjo.Android.Facebook)](https://github.com/mhdwaelanjo/Anjo.Android.Facebook/blob/master/LICENSE.txt)

This library allows you to integrate Facebook into your Android app.
Learn more about the provided samples, documentation, integrating the SDK into your app, accessing source code, and more at
https://developers.facebook.com/docs/android
